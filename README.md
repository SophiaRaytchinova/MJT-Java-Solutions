# ☕ MJT Java Solutions (2026-2027)

Решения на практическата част (упражнения и лаборатории) по курса **„Модерни Java технологии“** във ФМИ, Софийски университет.

---

## 📁 Структура на проектите

Всички решения са организирани по тематични подпапки:

* **`lab02-solution`** — Система за управление на паркинг (Parking System).
* **`lab03-solution`** — Система за симулация на една вечер в заведение (Stoyo's Tavern).
* **`lab03-solution`** — Система за записване на курсове (MayTheCourseBeWithYou).

---

##  Използвани технологии

* **Java SDK:** Version 21 (или по-нова)
* **IDE:** IntelliJ IDEA
